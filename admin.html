🏅 Rankings Override

ℹ️ How this works
📊 Auto column shows what the map currently displays — counties ranked by average TAT from your last upload.
📌 Override column lets you pin a specific county to that position. Leave it empty and the auto rank is used.
➕ + Add opens a search dropdown — find a county and click it to pin it to that slot. The county appears as a dark pill.
🥇🥇 Ties — if two counties tie for the same position, click + Add a second time on the same row to add another. Both get the same medal on the map.
✕ Click the ✕ on a pill to remove just that county. Click the ✕ button at the end of the row to clear the whole slot back to auto.
💾 Save when you’re done — changes go live on the public map instantly.
